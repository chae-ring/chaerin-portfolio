01

프로젝트 소개

hab-eat — AI 기반 식단 관리·습관 형성 서비스

사용자가 매번 직접 음식명을 검색하고 입력해야 하는 번거로움을 줄이기 위해 이미지 기반 음식 인식을 핵심 진입점으로 두었습니다. 서비스 API와 AI 추론 서버를 분리해 역할을 나누고, 식단 기록이 단순 기록에서 끝나지 않고 습관 형성으로 이어지도록 챌린지와 연결했습니다.

README처럼 “서비스가 왜 필요한지 → 무엇을 만들었는지 → 내가 어떤 문제를 풀었는지” 순서로 읽히도록 구성한 상세 페이지입니다.
02

주요 기능

음식 이미지 인식

사용자가 촬영한 음식 이미지를 AI 모델로 분류해 식단 입력을 돕습니다.

식단 기록

인식 결과를 기반으로 음식 정보를 저장하고 날짜별 식단을 확인합니다.

챌린지

목표와 기록을 연결해 사용자가 꾸준히 식습관을 관리하도록 구성합니다.

AI 서버 분리

서비스 API와 모델 추론 서버를 분리해 책임과 배포 단위를 나눕니다.

Problem Solving

채용 포트폴리오에서 가장 중요한 영역입니다. 단순 기능 나열보다 문제 → 원인 → 선택 → 결과가 보이게 작성합니다.

문제

AI 추론 로직과 일반 서비스 로직이 한 서버에 섞이면 배포와 장애 대응이 복잡해질 수 있었습니다.

접근

AI API 서버를 별도로 분리하고 서비스 서버가 추론 결과를 받아 처리하는 구조로 구성했습니다.

결과

기능 책임을 분리해 개발 범위를 명확히 하고 모델 교체 가능성을 높였습니다.

배운 점

AI 모델 자체뿐 아니라 모델을 서비스 구조 안에 안정적으로 연결하는 인터페이스 설계가 중요했습니다.
