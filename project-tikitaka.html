프로젝트 소개

Tikitaka — 실시간 강의·학습 플랫폼

강의 자료, 질문, 과제, 공지, 멤버 관리가 분산되어 있던 학습 경험을 하나의 SPACE 안에서 연결했습니다. 특히 질문이 많이 쌓일수록 같은 질문이 반복되는 문제를 해결하기 위해 임베딩 기반 유사도 계산과 그래프 연결 요소 기반 그룹화를 적용했습니다.

02

주요 기능

실시간 질문 관리

강의 중 질문을 빠르게 등록하고 조회할 수 있도록 질문 흐름을 구성했습니다.

유사 질문 자동 그룹화

Embedding + Cosine Similarity로 유사도를 수치화하고 Graph CC 방식으로 질문을 묶습니다.

Redis 캐시

임베딩과 반복 조회 데이터를 재사용해 불필요한 연산과 API 호출 비용을 줄입니다.

강의자료·과제·공지·멤버·질문 기능을 SPACE 중심으로 통합했습니다.

08

Problem Solving

채용 포트폴리오에서 가장 중요한 영역입니다. 단순 기능 나열보다 문제 → 원인 → 선택 → 결과가 보이게 작성합니다.

문제

질문 수가 늘수록 유사 질문 비교량이 증가하고 반복 연산 비용이 커졌습니다.

접근

질문 임베딩을 저장해 재사용하고, threshold 기반 간선 생성 후 연결 요소 단위로 그룹화했습니다.

결과

중복 질문을 자동으로 묶을 수 있는 구조를 만들고, 반복 AI 호출을 줄이는 방향으로 개선했습니다.

배운 점

정확도뿐 아니라 응답 속도, 비용, 재계산 범위를 함께 고려해야 운영 가능한 AI 기능이 된다는 점을 배웠습니다.
