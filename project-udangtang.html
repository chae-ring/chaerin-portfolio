01

프로젝트 소개

프로젝트 우당탕탕 — 프로젝트 의뢰·포트폴리오 웹사이트

단발성 프로젝트가 끝난 뒤 참여자 간 연결이 끊기는 문제에서 시작했습니다. 프로젝트 의뢰와 참여, 완료 프로젝트 아카이빙을 하나의 흐름으로 연결하고, 기존 참여자들이 자신이 만든 공간의 현재 상태를 다시 확인할 수 있도록 센서 데이터를 기반으로 공간의 ‘숨결’을 실시간 시각화했습니다.

README처럼 “서비스가 왜 필요한지 → 무엇을 만들었는지 → 내가 어떤 문제를 풀었는지” 순서로 읽히도록 구성한 상세 페이지입니다.
02

주요 기능

프로젝트 아카이빙

완료한 프로젝트의 배경·과정·결과를 스토리 형태로 정리합니다.

의뢰 흐름

방문자가 스튜디오의 역량을 이해한 뒤 자연스럽게 문의할 수 있게 구성합니다.

공간의 숨결

센서로 수집·가공한 공간 데이터를 서버 API로 받아 지도에서 공간별 활성 상태를 시각화합니다.

협업 연결

완료된 프로젝트의 공간과 참여자를 다시 연결해 성취감과 후속 참여로 이어지도록 설계합니다.

My Role & Contribution

서비스 구조 설계

문제 정의부터 핵심 사용자 흐름과 페이지 구조를 정리합니다.

요구사항 정리

스튜디오의 강점과 외부 협업자의 강점이 어떻게 연결되는지 콘텐츠 구조에 반영합니다.

프론트엔드·백엔드

웹사이트의 프론트엔드와 백엔드 전반을 개발하고 프로젝트 의뢰·참여·관리자 기능을 구현했습니다.

하드웨어 API 연동

하드웨어 담당자가 수집·가공한 센서 데이터를 서버 API로 연결하고, 지도 기반 공간별 숨결 시각화 흐름을 구현했습니다.

08

Problem Solving

채용 포트폴리오에서 가장 중요한 영역입니다. 단순 기능 나열보다 문제 → 원인 → 선택 → 결과가 보이게 작성합니다.

문제

접근
